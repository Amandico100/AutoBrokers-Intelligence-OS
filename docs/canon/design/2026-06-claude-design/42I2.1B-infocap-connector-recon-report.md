## 4. Endpoint de probe (criado)
`POST /api/attendance/connectors/infocap/probe` (Iron Session) → backend `POST /attendance/connectors/infocap/probe` (chave interna). Body:
```json
{ "query_type": "cpf", "query": "<CPF ou nome>", "codfil": 1 }
```
O backend faz login uma vez e testa (read-only) vários endpoints. Para CPF: `/busca_cpf?cpf_cnpj=<digits>`, `/busca_cpf?cpf_cnpj=<fmt>`, `/cliente_cpf?codfil&cpf_cnpj=<digits>`, `/cliente_cpf?codfil&cpf_cnpj=<fmt>`, `/producao?texto=<digits>`. Para nome: `/lista_clientes?texto=`, `/producao?texto=`.

## 5. Saída segura (exemplo)
```json
{
  "ok": true,
  "provider": "infocap",
  "auth_http_status": 200,
  "query_type": "cpf",
  "winner_endpoint": "/cliente_cpf?codfil=N&cpf_cnpj=***",
  "winner_array_key": "data",
  "winner_sample_keys": ["codcli","codfil","cliente","numapo","seguradora_abrev","ramo_abrev","sit_acompanhamento_txt"],
  "probes": [
    { "endpoint": "/busca_cpf?cpf_cnpj=***", "http_status": 200, "ok": true, "result_count": 0, "raw_type": "object", "top_level_keys": ["sucesso","mensagem"], "array_key_detected": null, "sample_keys": [], "status_hint": "ok" },
    { "endpoint": "/cliente_cpf?codfil=N&cpf_cnpj=***", "http_status": 200, "ok": true, "result_count": 1, "raw_type": "object", "array_key_detected": "data", "sample_keys": ["codcli","cliente","numapo", "..."], "status_hint": "ok" }

```
Cada probe retorna **só**: `endpoint` (mascarado), `method`, `http_status`, `ok`, `result_count`, `raw_type`, `top_level_keys`, `array_key_detected`, `sample_keys`, `status_hint`, `error_hint`. **Nunca** valores/CPF/token/payload.

## 7. Conclusão técnica / fluxo definitivo
`login → search (endpoint correto descoberto pelo probe) → (se houver codcli/nosnum/numapo) detail via /cliente|/documento|/producao → normalized evidence`. Quando o probe revelar o endpoint/array_key/keys reais, o lookup definitivo será apontado **via `connection_config`** (sem mudar código): `infocap_cpf_search_path`, `infocap_cpf_search_param`, `infocap_search_extra_params` (ex.: `{"codfil":1}`), `infocap_search_path`, `infocap_search_param`. Se o array vier numa chave fora de `ARRAY_KEYS`, o `_extract_array` já tenta qualquer lista de objetos; se necessário, adiciono a chave exata no 42I2.1C.

## 8. Logs / segurança
Backend loga só `company`, `connection`, `endpoint` (mascarado), `http_status`, `result_count`, `duration_ms`. Sem CPF/login/senha/token/ciphertext/payload. Probe é **read-only** (só GET de consulta) e **não persiste** nada no caso.
