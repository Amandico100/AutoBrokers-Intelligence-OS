## 4. Como separar oficial vs bruto
Toda definição global carrega `metadata.source_type = 'official_research'`, `metadata.confidence`, `metadata.official_sources` e `metadata.checked_at`. As regras (`classifyPortalSourceConfidence`): `confirmed` + https + audiência operacional (corretor/segurado/parceiro) → `sandbox_ready`; `confirmed` (dev/interno/terceiro), `strong_evidence`, `partial_evidence` → `needs_review`; `unconfirmed`/sem https → **ignorado** (não entra). Dados brutos de conversas (intake) **não** entram no catálogo — só os metadados de portal pesquisados.

## 5. Onde fica o Global Catalog
- **Importer puro:** `lib/attendance/portal-intake-importer.ts` (parser CSV/markdown, mapeamento, confiança, dedupe, pipeline).
- **Gerador:** `scripts/generate-portal-global-catalog.mjs` (lê o CSV, roda o importer, escreve o seed).
- **Seed commitado (artefato):** `lib/attendance/portal-global-catalog-seed.ts` (`PORTAL_GLOBAL_CATALOG_SEED` + stats; auto-gerado, sem credencial).
- **Acessor:** `lib/attendance/portal-global-catalog.ts` (`getGlobalPortalCatalogSeed`, `filterGlobalCatalog`, `sanitizeGlobalCatalogEntry`, `getGlobalCatalogStats`).
O catálogo **não** é lido do CSV em runtime de produção — vira um seed estático revisável em PR. Regenerar = rodar o script.
