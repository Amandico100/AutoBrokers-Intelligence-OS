# Assistente de passkey AutoBrokers 0.7.2-ab1

Extensão Chromium restrita a `https://web.whatsapp.com`. Ela executa a
cerimônia WebAuthn exigida pelo WhatsApp e se comunica exclusivamente com o
endpoint fixo do Evolution Go da AutoBrokers.

A extensão não lê conversas, não coleta dados e não solicita senha, PIN ou
passkey. A biometria ou o bloqueio são tratados pelo navegador e pelo sistema
operacional.

Instale a pasta descompactada pelo modo de desenvolvedor do Chrome ou Edge e
depois use **Abrir WhatsApp Web** na tela de pareamento.
